# SmartPark: Design Sprint Deliverables

The design-sprint write-up for **SmartPark**, a campus parking app that shows live garage availability and guides drivers to an open spot. It's a single self-contained HTML page.

## Contents

- Product vision
- Personas (imagined users)
- User journey map
- Stakeholders
- Ask the experts
- Problem-validation survey
- How Might We… (HMW) notes
